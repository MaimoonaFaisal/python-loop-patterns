# Nested While Loop Patterns

Python scripts practicing **nested `while` loops** and controlling console line breaks.

## Files Included
* **`mx9.py`**: Uses `#print("")` (commented out) so all 25 asterisks (`*`) print side by side on a single continuous line.
* **`mx10.py`**: Activates `print("")` on each outer loop pass to break the stars into a neat 5x5 square grid.

## Output Preview (`mx10.py`)
```text
* * * * * 
* * * * * 
* * * * * 
* * * * * 
* * * * * 
```

## Concepts Learned
* Managing counter variables (`i += 1`, `j += 1`) inside nested `while` loops.
* Resetting inner loop counters between outer iterations.
* Using `end=" "` and empty `print()` statements to format pattern layouts.
